Рейтинг игроков

Загрузка…

В таблице — игроки с хотя бы одной рейтинговой партией. Рейтинговая партия: онлайн, оба игрока вошли через Google, сыграно не меньше 3 ходов каждым. Рейтинг считается по системе Эло отдельно для каждой игры и категории времени: пуля (до 3 минут), блиц (до 8), рапид (до 25), классика (дольше). Категория определяется по формуле «минуты × 60 + добавление × 40 секунд». Нажмите на игрока, чтобы открыть профиль.

Один аккаунт на обе игры. Войдите через Google — и онлайн-партии сохранятся в вашей истории.
Совет: установите страницу как приложение — тогда обе игры доступны с экрана телефона.
